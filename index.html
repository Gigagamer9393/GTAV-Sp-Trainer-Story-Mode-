GET STARTED

ASI MENU INSTALLATION

Complete GTA V Story Mode setup with Script Hook V, the ASI Loader and optional Script Hook V .NET.

Official Script Hook V Script Hook V .NET (optional)
01

Open the GTA V main folder

Open the folder that contains GTA5.exe. On Steam, Epic or the Rockstar Games Launcher you can use the launcher option to browse/open the installed game files. Back up important files and saves before modding.

02

Download Script Hook V

Download the current Script Hook V release from Alexander Blade's official page. Check the supported game patches shown there, especially after a GTA V update.

03

Install Script Hook V + ASI Loader

Open the Script Hook V archive and copy ScriptHookV.dll and dinput8.dll into the GTA V main folder next to GTA5.exe. dinput8.dll is the ASI Loader. If an old ASI Loader such as dsound.dll is installed, remove the old loader to avoid conflicts.

04

Native Trainer is optional

The Script Hook V package can also contain NativeTrainer.asi. It is only a sample trainer and is not required for your own ASI menu. Copy it only if you actually want to use it.

05

Install your ASI menu

Extract your downloaded menu. A normal .asi menu usually goes directly into the GTA V main folder next to GTA5.exe, ScriptHookV.dll and dinput8.dll. Copy any included .ini, .dll, data folders or other files exactly as described by the menu's readme.

06

.NET only when required

Do not install Script Hook V .NET unless the mod explicitly needs it. If required, install its prerequisites and copy ScriptHookVDotNet.asi, ScriptHookVDotNet2.dll and ScriptHookVDotNet3.dll from the same release into the GTA V main folder. Create/use the scripts folder for .NET scripts.

07

Start GTA V Story Mode

Launch GTA V and enter Story Mode only. Open the menu with the key stated by that menu, for example a function key or numpad key. Script Hook V is intended for singleplayer scripting and does not work in GTA Online.

08

After a GTA V update

If a game update causes the menu to stop loading, first check whether a newer Script Hook V version supports the new game build. Replace the old Script Hook V runtime with the current compatible release before blaming the menu itself.

09

Updating your menu

When updating a menu, follow its included instructions. Back up custom configuration files first. Do not mix files from different Script Hook V .NET releases; its ASI and API DLL files should be updated together.

TYPICAL FILE LAYOUT

What the GTA V folder usually looks like

Grand Theft Auto V/
├─ GTA5.exe
├─ ScriptHookV.dll
├─ dinput8.dll              ← ASI Loader
├─ YourMenu.asi             ← your ASI menu
├─ YourMenu.ini             ← only if included
└─ scripts/                 ← only for mods that require SHVDN
?

Menu does not open

Check that dinput8.dll, ScriptHookV.dll and the menu's .asi file are next to GTA5.exe. Also check the menu's hotkey and whether its version supports your game build.

!

Game crashes on startup

Temporarily remove third-party ASI mods and add them back one at a time. Conflicting or outdated ASI plugins are a common cause. Also make sure an old dsound.dll loader is not conflicting with dinput8.dll.

↻

Worked before an update

Game updates can temporarily break Script Hook V compatibility. Check the official Script Hook V page for a build that supports your current GTA V patch.

Important: This guide is for GTA V Story Mode / Singleplayer. Do not use these menus in GTA Online.
RDR2: Red Dead Redemption 2 uses its own compatible loader/setup. Do not copy GTA V's ScriptHookV.dll into RDR2.

ASI-MENÜ INSTALLIEREN

Komplette GTA-V-Story-Mode-Anleitung mit Script Hook V, ASI Loader und optional Script Hook V .NET.

Offizielles Script Hook V Script Hook V .NET (optional)
01

GTA-V-Hauptordner öffnen

Öffne den Ordner, in dem GTA5.exe liegt. Bei Steam, Epic oder dem Rockstar Games Launcher kannst du über die Launcher-Funktion die installierten Spieldateien öffnen. Erstelle vor dem Modding ein Backup wichtiger Dateien und Spielstände.

02

Script Hook V herunterladen

Lade die aktuelle Script-Hook-V-Version von der offiziellen Seite von Alexander Blade herunter. Prüfe dort besonders nach einem GTA-V-Update, welche Spiel-Patches aktuell unterstützt werden.

03

Script Hook V + ASI Loader installieren

Öffne das Script-Hook-V-Archiv und kopiere ScriptHookV.dll sowie dinput8.dll in den GTA-V-Hauptordner direkt neben GTA5.exe. dinput8.dll ist der ASI Loader. Falls noch ein alter ASI Loader wie dsound.dll vorhanden ist, entferne den alten Loader, damit es keine Konflikte gibt.

04

Native Trainer ist optional

Im Script-Hook-V-Paket kann zusätzlich NativeTrainer.asi enthalten sein. Das ist nur ein Beispiel-Trainer und für dein eigenes ASI-Menü nicht erforderlich. Kopiere ihn nur, wenn du ihn wirklich verwenden möchtest.

05

Dein ASI-Menü installieren

Entpacke dein heruntergeladenes Menü. Eine normale .asi-Datei kommt üblicherweise direkt in den GTA-V-Hauptordner neben GTA5.exe, ScriptHookV.dll und dinput8.dll. Mitgelieferte .ini-, .dll-, Datenordner oder sonstige Dateien kopierst du genau so, wie es in der Readme des Menüs angegeben ist.

06

.NET nur wenn wirklich benötigt

Installiere Script Hook V .NET nur, wenn dein Mod es ausdrücklich verlangt. Falls nötig, installiere die Voraussetzungen und kopiere ScriptHookVDotNet.asi, ScriptHookVDotNet2.dll und ScriptHookVDotNet3.dll aus derselben Version in den GTA-V-Hauptordner. Für .NET-Skripte wird der Ordner scripts verwendet.

07

GTA V im Story Mode starten

Starte GTA V und gehe ausschließlich in den Story Mode. Öffne das Menü mit der Taste, die für dein Menü angegeben ist, zum Beispiel einer F-Taste oder einer Numpad-Taste. Script Hook V ist für Singleplayer-Skripte gedacht und funktioniert nicht in GTA Online.

08

Nach einem GTA-V-Update

Falls das Menü nach einem Spiel-Update nicht mehr lädt, prüfe zuerst, ob eine neue Script-Hook-V-Version den neuen GTA-V-Build unterstützt. Ersetze die alte Script-Hook-V-Runtime durch die aktuelle kompatible Version, bevor du von einem Fehler im Menü ausgehst.

09

Menü aktualisieren

Halte dich beim Update des Menüs an die beiliegende Anleitung und sichere vorher eigene Konfigurationsdateien. Mische bei Script Hook V .NET keine Dateien aus verschiedenen Releases; ASI- und API-DLL-Dateien sollten gemeinsam aktualisiert werden.

TYPISCHER DATEIAUFBAU

So sieht dein GTA-V-Ordner meistens aus

Grand Theft Auto V/
├─ GTA5.exe
├─ ScriptHookV.dll
├─ dinput8.dll              ← ASI Loader
├─ DeinMenu.asi             ← dein ASI-Menü
├─ DeinMenu.ini             ← nur falls enthalten
└─ scripts/                 ← nur für Mods mit SHVDN
?

Menü öffnet sich nicht

Prüfe, ob dinput8.dll, ScriptHookV.dll und die .asi-Datei deines Menüs direkt neben GTA5.exe liegen. Prüfe außerdem die Menütaste und ob die Menüversion deinen GTA-V-Build unterstützt.

!

Spiel stürzt beim Start ab

Entferne testweise Drittanbieter-ASI-Mods und füge sie danach einzeln wieder hinzu. Veraltete oder miteinander kollidierende ASI-Plugins sind eine häufige Ursache. Prüfe außerdem, dass kein alter dsound.dll-Loader mit dinput8.dll kollidiert.

↻

Vor dem Update ging es noch

GTA-V-Updates können die Kompatibilität von Script Hook V vorübergehend unterbrechen. Prüfe auf der offiziellen Script-Hook-V-Seite, ob dein aktueller GTA-V-Patch unterstützt wird.

Wichtig: Diese Anleitung ist ausschließlich für GTA V Story Mode / Singleplayer. Verwende die Menüs nicht in GTA Online.
RDR2: Red Dead Redemption 2 verwendet ein eigenes kompatibles Loader-/Setup-System. Kopiere GTA Vs ScriptHookV.dll nicht nach RDR2.
